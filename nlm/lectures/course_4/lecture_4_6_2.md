# Lecture 4.6.2: Intrinsic Value

**Course:** 4 | **Chapter:** Chapter 4.6: Option Premium, Intrinsic & Time Value | **Lecture:** 4.6.2

**Concept:** Premium = Intrinsic Value + Time Value.

---

Intrinsic value is the inherent value of an option if it were exercised immediately. It is the amount the option is 'in-the-money'. For a Call option, intrinsic value is (Current Price - Strike Price). For a Put option, it is (Strike Price - Current Price). If the option is 'out-of-the-money' or 'at-the-money', its intrinsic value is zero. Intrinsic value cannot be negative.
