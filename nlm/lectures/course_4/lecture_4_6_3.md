# Lecture 4.6.3: Time Value

**Course:** 4 | **Chapter:** Chapter 4.6: Option Premium, Intrinsic & Time Value | **Lecture:** 4.6.3

**Concept:** Premium = Intrinsic Value + Time Value.

---

Time value is the portion of the premium that is not intrinsic value. It represents the potential for the option to increase in value before expiry. Time value decays as the expiration date approaches, a phenomenon known as 'time decay' (Theta). The longer the time to expiry, the higher the time value. This is why options are a 'wasting asset'. Time decay accelerates in the last 30 days before expiry. For example, an option with 30 days to expiry has more time value than one with 5 days to expiry.
